# Nur frisch gemixt!
Auch wenn es inzwischen überall fertig gemischte Spritz-Getränke gibt und diese für einen Tag im Park bestimmt optimal sind, sollen sie **nicht** in dieser Karte eingetragen werden. 

Ein echter Spritz wird frisch gemischt!

# Die Farbe verrät mehr
Je **kräftiger** die Farbe eines Glases, desto mehr Aperol (bzw. Likör) ist im Glas.

Helle Gläser = viel Prosecco. Kräftige Gläser = viel Likör.
